# modelBuild:material

Makes a named colour a display may repaint; `grain` (0 to 1) darkens pixels into four tones, `alpha` below 1 is glass.

```
modelBuild:material(name: string, color: Ink, opts: { grain: number?, alpha: number? }?) → ModelMaterial
```
