# bar.visible

Whether players see the bar; false takes it off their screens, true or nil shows it again.

```
bar.visible: boolean?
```


## Used in
- [`bar.title, bar.progress, bar.color, bar.visible -- live; progress 0..1`HUD](/docs/citadel/hud)
- [`bar.visible = false -- off every screen; true or nil shows it again`HUD](/docs/citadel/hud)
