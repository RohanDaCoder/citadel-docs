

===== REF: AskCount =====
TITLE: AskCount type
LEAD: What one kind of ask has cost this pack, and what every kind has together. An ask is a question the engine puts to a pack with a deadline on it; an answer that does not arrive in time is not used.
SECTIONS: [{'title': 'Fields 6', 'type': 'fields'}]
  [fields] askCount.asks: number :: Questions the engine put to this pack.
  [fields] askCount.answered: number :: Answers that arrived in time.
  [fields] askCount.missed: number :: Deadlines that passed with no answer.
  [fields] askCount.late: number :: Answers that arrived after the engine had acted, and were dropped.
  [fields] askCount.skipped: number :: Asks never sent, because this kind is switched off for this pack.
  [fields] askCount.disabled: boolean :: True once the engine has stopped asking this pack this kind at all.

  [functions] blockAmendSpec.on_step((block: BlockAt, body: Body, base: (... any) -> any) -> ()) → ? :: A body (a player, mob, item or other) is standing on it.
  [functions] blockAmendSpec.on_tick((block: BlockAt, base: (... any) -> any) -> ()) → ? :: A scheduled tick this block asked for came due.

  [functions] blockAmendSpec.on_neighbour((block: BlockAt, from: Vec3, announced: string, base: (... any) -> any) -> ()) → ? :: A neighbour at `from` changed; `announced` is the block the notifier announced itself as.

  [functions] blockAmendSpec.on_added((block: BlockAt, base: (... any) -> any) -> ()) → ? :: It has just been stored, whatever stored it.

===== REF: BlockAt =====
TITLE: BlockAt type
LEAD: The block a hook was called about. Reads are fields and acts are methods. The reads are **live** — the world as it is right now — and everything that changes the world is carried out by the engine the moment the hook returns, in the order it was asked for.
SECTIONS: [{'title': 'Functions 7', 'type': 'functions'}, {'title': 'Fields 7', 'type': 'fields'}]
  [functions] blockAt:get(face: Face) → string ? :: The block one face away, by name; nil where that chunk is not in memory.
  [functions] blockAt:set(block: BlockRef) :: Puts another block at this position.
  [functions] blockAt:destroy() :: Takes it out, leaving nothing.
  [functions] blockAt:become(entity: string, data: { [string]: any }?) :: **The door**: this block stops being a block, and that entity appears.
  [functions] blockAt:drop(item: ItemSpec, count: number ?) :: A name, or an item table: a pack item keeps its id.
  [functions] blockAt:schedule() :: Asks for this block's `on_tick`, `tick_every` seconds from now.
  [functions] blockAt:notify() :: Tells the six neighbours this block changed.
  [fields] blockAt.data: DataView :: What this block remembers beyond its state; kept with the position, saved with the chunk, and gone when the block goes. Nested writes are tracked; whole-record assignment is supported. Copy before keeping it beyond the hook.
  [fields] blockAt.at: Vec3 :: The block's position; a live read.
  [fields] blockAt.name: string :: The block's name with its namespace, such as "rave:crate"; a live read.
  [fields] blockAt.room: number :: Which room the block is in.
  [fields] blockAt.state: number :: Which of this definition's states it is in, counting from 1. Writable, and bounds-checked against the definition's own `looks` list: it *is* the block state, so a crop's stages cost nothing.
  [fields] blockAt.facing: Facing ? :: A facing block's front: "north", "south", "west", "east"; nil otherwise. Writable.
  [fields] blockAt.powered: boolean ? :: Whether a redstone signal reaches it: what a lamp asks. A live read; nil where the chunk is not loaded.

===== REF: BlockSpec =====
TITLE: BlockSpec type
LEAD: What a definition says a block *is*. Every hook takes `base` as its **last** argument: call it and you extended what is under you, leave it out and you replaced it. `base` is a decision rather than a reentrant call — its effects land when your hook returns, and calling it twice happens once.
SECTIONS: [{'title': 'Functions 11', 'type': 'functions'}, {'title': 'Fields 16', 'type': 'fields'}]
  [functions] blockSpec.on_use((block: BlockAt, player: Player ?, held: string ?, base: (... any) -> any) -> Used ?) → ? :: The hooks. Writing one is what asks for it — there is no flag beside `on_random_tick` saying the random pass may land here.
  [functions] blockSpec.on_break((block: BlockAt, player: Player ?, by: Breaker, base: (... any) -> any) -> Drops ?) → ? :: Something broke it. Answers "none", "table" or a drops list; fails closed to the definition's `drops`.
  [functions] blockSpec.on_step((block: BlockAt, body: Body, base: (... any) -> any) -> ()) → ? :: A body is standing on it; `body` is `{ id, kind }`.
  [functions] blockSpec.on_tick((block: BlockAt, base: (... any) -> any) -> ()) → ? :: A scheduled tick this block asked for came due.
  [functions] blockSpec.on_random_tick((block: BlockAt, base: (... any) -> any) -> ()) → ? :: The random pass landed on it. Not the same thing as `on_tick`, which is why it has the longer name.
  [functions] blockSpec.on_place((block: BlockAt, player: Player ?, base: (... any) -> any) -> ()) → ? :: A player put it down; `block.data` is empty then, ready to be filled.
  [functions] blockSpec.on_neighbour((block: BlockAt, from: Vec3, announced: string, base: (... any) -> any) -> ()) → ? :: A neighbour changed; `from` is its position and `announced` the block name the notifier announced itself as.
  [functions] blockSpec.on_trigger((block: BlockAt, cause: Trigger, base: (... any) -> any) -> ()) → ? :: It was lit, blasted or burnt; `cause` is "ignite", "explosion" or "fire".
  [functions] blockSpec.on_power((block: BlockAt, powered: boolean, base: (... any) -> any) -> ()) → ? :: A redstone signal started (`powered` is true) or stopped reaching it. Called once for each, not for every change beside it.
  [functions] blockSpec.on_added((block: BlockAt, base: (... any) -> any) -> ()) → ? :: It has just been stored, whatever stored it.
  [functions] blockSpec.on_removed((block: BlockAt, base: (... any) -> any) -> ()) → ? :: It has just gone from the world.
  [fields] blockSpec.name: string :: Without a namespace. The pack's own is put in front of it, and a colon here is refused: a pack cannot write another pack's name.
  [fields] blockSpec.looks: (string | { string })? :: A block state the client already draws, because a client has never heard of this pack. One name, or one per state in state order. `|` takes the first this version has: "crimson_planks|nether_brick".
  [fields] blockSpec.hardness: number ? :: Seconds-scale, as vanilla's hardness is; below zero is unbreakable.
  [fields] blockSpec.resistance: number ? :: What an explosion has to chew through.
  [fields] blockSpec.material: { solid: boolean ?, covers: boolean ?, firm: boolean ?, liquid: boolean ?, burns: boolean ?, }? :: The jar's Material as five questions: solid, covers (grass under it dies), firm (snow and ice need it), liquid, burns.
  [fields] blockSpec.opacity: number ? :: What a step through it takes off the light; 15 is an opaque cube.
  [fields] blockSpec.light: number ? :: What it gives off, 0 to 15.
  [fields] blockSpec.tick_every: number ? :: Seconds between `block:schedule()` and `on_tick`; 0.5 unless you say.
  [fields] blockSpec.drops: (Drops | false)? :: What a break leaves — and, because `on_break` fails closed, what it leaves when this pack is too slow to answer. Never the looks block's. false is nothing, as "none" is.
  [fields] blockSpec.item: (ItemTable | false)? :: The block in a hand. Its `id` is set to the block's name, so placing it puts this block down, and a break leaves it unless `drops` says. false is no item, also for a block with a texture.
  [fields] blockSpec.texture: (Faces | { Faces })? :: Its own picture on 1.21.4+: one for every state, or one per state.
  [fields] blockSpec.model: (Model | { Model })? :: Its own shape on 1.21.4+, in place of `texture`: a model that stays inside the block, one for every state or one per state. The block collides as its `looks` block does: "rail" is walked through.
  [fields] blockSpec.facing: boolean ? :: Turns its front to whoever places it; `block.facing` reads and turns it.
  [fields] blockSpec.power: (number | { [string]: number } | { number | { [string]: number } })? :: What it gives a redstone circuit, 0 or 15: one number for every face, a table keyed by face (the names `texture` takes), or a list of either with one entry per state. It is the power a block of redstone gives.
  [fields] blockSpec.label: Text ? :: The name of the item a textured block comes with.
  [fields] blockSpec.extends: (BlockRef | { [string]: any } | { any })? :: A handle, a game block's name, a plain table of fields and hooks, or a list of those **innermost first**. There is no class and no metatable: fields merge and hooks wrap.
