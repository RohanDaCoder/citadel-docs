---
title: "entityHandle:move"
description: "Gone on the next tick"
---

Part of [`EntityHandle`](/ref/EntityHandle/).

```luau
entityHandle:move(at: Vec3, rotation: BodyRotation ?)
```

Gone on the next tick. Sets position and optional rotation together.

## Parameters

| Name       | Type                                 | Required |
| ---------- | ------------------------------------ | -------- |
| `at`       | [`Vec3`](/ref/Vec3/)                 | yes      |
| `rotation` | [`BodyRotation`](/ref/BodyRotation/) | no       |
