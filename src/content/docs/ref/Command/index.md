A command a pack added, from `commands.add`; change its suggestions or `cancel` it.

## Functions

| Call | Purpose |
| --- | --- |
| [`suggest`](/ref/Command/suggest/) | What `arg` offers from now on: a list, a function, or nil or false for nothing. |
| [`cancel`](/ref/Command/cancel/) | Takes the command away. |
