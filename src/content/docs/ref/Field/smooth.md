---
title: "field:smooth"
description: "0 at from, 1 at to, smooth between"
---

Part of [`Field`](/ref/Field/).

```luau
field:smooth(from: number, to: number) → Field
```

0 at `from`, 1 at `to`, smooth between. `from` may be the larger.

## Parameters

| Name   | Type     | Required |
| ------ | -------- | -------- |
| `from` | `number` | yes      |
| `to`   | `number` | yes      |

## Returns

- [`Field`](/ref/Field/)
