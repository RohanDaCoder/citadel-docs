Part of [`ModelPart`](/ref/ModelPart/).

```luau
modelPart:mirror(axis: "x")
```

A mirrored copy of every box and hitbox this part has, and a mirrored twin named `<name>_mirrored` of every child. Only "x" in this version.

## Parameters

| Name   | Type  | Required |
| ------ | ----- | -------- |
| `axis` | `"x"` | yes      |
