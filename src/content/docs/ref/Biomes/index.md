## Functions

| Call                            | Purpose                                                                                                                                                                      |
| ------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`define`](/ref/Biomes/define/) | Defines a biome, or changes the one of that name, and returns its full name ("mypack:crystal"). Call it at the top of the script: a player learns the biomes when they join. |
