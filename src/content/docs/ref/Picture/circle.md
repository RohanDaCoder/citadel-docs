---
title: "picture:circle"
description: "Fills a circle of radius r pixels around (x, y)."
---

Part of [`Picture`](/ref/Picture/).

```luau
picture:circle(x: number, y: number, r: number, color: Ink)
```

Fills a circle of radius `r` pixels around (x, y).

## Parameters

| Name    | Type               | Required |
| ------- | ------------------ | -------- |
| `x`     | `number`           | yes      |
| `y`     | `number`           | yes      |
| `r`     | `number`           | yes      |
| `color` | [`Ink`](/ref/Ink/) | yes      |
