---
title: "picture:rect"
description: "Fills a box like fill, with smoothed rounded corners of radius pixels when given."
---

Part of [`Picture`](/ref/Picture/).

```luau
picture:rect(x: number, y: number, w: number, h: number, color: Ink, radius: number ?)
```

Fills a box like `fill`, with smoothed rounded corners of `radius` pixels when given.

## Parameters

| Name     | Type               | Required |
| -------- | ------------------ | -------- |
| `x`      | `number`           | yes      |
| `y`      | `number`           | yes      |
| `w`      | `number`           | yes      |
| `h`      | `number`           | yes      |
| `color`  | [`Ink`](/ref/Ink/) | yes      |
| `radius` | `number`           | no       |
