Part of [`Picture`](/ref/Picture/).

```luau
picture:pixels(x: number, y: number, w: number, h: number, data: buffer | string)
```

Writes raw RGB bytes (a buffer or a string), three a pixel, row by row, into a w by h box.

## Parameters

| Name | Type | Required |
| --- | --- | --- |
| `x` | `number` | yes |
| `y` | `number` | yes |
| `w` | `number` | yes |
| `h` | `number` | yes |
| `data` | `buffer \| string` | yes |
