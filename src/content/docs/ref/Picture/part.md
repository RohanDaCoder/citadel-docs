Part of [`Picture`](/ref/Picture/).

```luau
picture:part(col: number, row: number) → { id: number }
```

One map of the picture, `{ id = .. }`, by column and row from (0, 0) top- left; for a hand or a single frame.

## Parameters

| Name | Type | Required |
| --- | --- | --- |
| `col` | `number` | yes |
| `row` | `number` | yes |

## Returns

- `{ id: number }`
