Part of [`Picture`](/ref/Picture/).

```luau
picture:ring(x: number, y: number, r: number, color: Ink, width: number ?)
```

Draws a circle's outline, `width` pixels wide (1 by default), smoothed.

## Parameters

| Name | Type | Required |
| --- | --- | --- |
| `x` | `number` | yes |
| `y` | `number` | yes |
| `r` | `number` | yes |
| `color` | [`Ink`](/ref/Ink/) | yes |
| `width` | `number` | no |
