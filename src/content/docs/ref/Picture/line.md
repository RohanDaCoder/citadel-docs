---
title: 'picture:line'
description: 'Draws a smoothed line with round ends, width pixels wide (1 by default); positions may be fractions.'
---

Part of [`Picture`](/ref/Picture/).

```luau
picture:line(x0: number, y0: number, x1: number, y1: number, color: Ink, width: number ?)
```

Draws a smoothed line with round ends, `width` pixels wide (1 by default); positions may be fractions.

## Parameters

| Name | Type | Required |
| --- | --- | --- |
| `x0` | `number` | yes |
| `y0` | `number` | yes |
| `x1` | `number` | yes |
| `y1` | `number` | yes |
| `color` | [`Ink`](/ref/Ink/) | yes |
| `width` | `number` | no |
