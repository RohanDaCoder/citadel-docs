Part of [`Picture`](/ref/Picture/).

```luau
picture:text(x: number, y: number, text: string, color: Ink, size: number ?) → number
```

Draws text in DejaVu Sans Bold, `size` pixels tall (16 by default), smoothed; returns its width in pixels.

## Parameters

| Name | Type | Required |
| --- | --- | --- |
| `x` | `number` | yes |
| `y` | `number` | yes |
| `text` | `string` | yes |
| `color` | [`Ink`](/ref/Ink/) | yes |
| `size` | `number` | no |

## Returns

- `number`
