Part of [`Picture`](/ref/Picture/).

```luau
picture:fill(x: number, y: number, w: number, h: number, color: Ink)
```

Fills a w by h box of pixels with one colour, its top-left at (x, y).

## Parameters

| Name    | Type               | Required |
| ------- | ------------------ | -------- |
| `x`     | `number`           | yes      |
| `y`     | `number`           | yes      |
| `w`     | `number`           | yes      |
| `h`     | `number`           | yes      |
| `color` | [`Ink`](/ref/Ink/) | yes      |
