Part of [`Picture`](/ref/Picture/).

```luau
picture:clear(color: Ink ?)
```

Its width in pixels: 128 for each map across. Its height in pixels: 128 for each map down. Paints every pixel one colour; black by default. On a view, the default clears it to see-through.

## Parameters

| Name    | Type               | Required |
| ------- | ------------------ | -------- |
| `color` | [`Ink`](/ref/Ink/) | no       |
