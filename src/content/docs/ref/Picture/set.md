Part of [`Picture`](/ref/Picture/).

```luau
picture:set(x: number, y: number, color: Ink)
```

Paints one pixel; (0, 0) is the top-left.

## Parameters

| Name | Type | Required |
| --- | --- | --- |
| `x` | `number` | yes |
| `y` | `number` | yes |
| `color` | [`Ink`](/ref/Ink/) | yes |
