---
title: 'npc:move'
description: 'Removes the NPC'
---

Part of [`Npc`](/ref/Npc/).

```luau
npc:move(at: Vec3, rotation: BodyRotation ?)
```

Removes the NPC. Sets position and optional rotation together.

## Parameters

| Name | Type | Required |
| --- | --- | --- |
| `at` | [`Vec3`](/ref/Vec3/) | yes |
| `rotation` | [`BodyRotation`](/ref/BodyRotation/) | no |
