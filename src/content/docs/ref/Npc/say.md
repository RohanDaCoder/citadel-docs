Part of [`Npc`](/ref/Npc/).

```luau
npc:say(text: Text, color: Ink ?)
```

Sends a chat line "<name> ..." to the room, or just the words for an NPC with no name.

## Parameters

| Name    | Type                 | Required |
| ------- | -------------------- | -------- |
| `text`  | [`Text`](/ref/Text/) | yes      |
| `color` | [`Ink`](/ref/Ink/)   | no       |

## Used in

> "color)`, a title's `color`, a text display's `color`, `npc:say(text," — [Text formatting](/ui/ui-basics/)
