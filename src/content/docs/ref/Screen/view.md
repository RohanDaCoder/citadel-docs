```luau
screen:view(player: Player) → View
```

Returns this player's own layer over the screen; only they see it, and the shared picture shows where it is see-through.

## Parameters

| Name | Type | Required |
| --- | --- | --- |
| `player` | [`Player`](/ref/Player/) | yes |

## Returns

- [`View`](/ref/View/)
