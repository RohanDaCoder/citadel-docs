title: "player:kick"

Part of [`Player`](/ref/Player/).

```luau
player:kick(reason: Text ?)
```

Disconnects the player, with that text on their screen.

## Parameters

| Name     | Type                 | Required |
| -------- | -------------------- | -------- |
| `reason` | [`Text`](/ref/Text/) | no       |

## Used in

> "player:kick("Server full") -- disconnect them, with that text on their screen" — [Body and movement](/players/movement/)
