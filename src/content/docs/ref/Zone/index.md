A box of blocks that knows who is in it, checked once a tick.

## Functions

| Call                              | Purpose                                      |
| --------------------------------- | -------------------------------------------- |
| [`contains`](/ref/Zone/contains/) | Returns true when the player is in the zone. |
| [`players`](/ref/Zone/players/)   | Returns who is in the zone now.              |
| [`destroy`](/ref/Zone/destroy/)   | Removes the zone.                            |
