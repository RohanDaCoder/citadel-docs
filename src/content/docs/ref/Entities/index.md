`game.entities`: the three verbs over one shape.

## Functions

| Call | Purpose |
| --- | --- |
| [`define`](/ref/Entities/define/) | Load time only. A definition is a fact about the world. |
| [`amend`](/ref/Entities/amend/) | The game's own content only — never another pack's. |
| [`names`](/ref/Entities/names/) | Every kind by name: the pack's own and the game's, mob or not. `mob = true` gives the mob kinds only, `mob = false` the rest. |
