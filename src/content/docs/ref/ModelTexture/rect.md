---
title: "modelTexture:rect"
description: "Paints a rectangle w by h pixels from x, y."
---

Part of [`ModelTexture`](/ref/ModelTexture/).

```luau
modelTexture:rect(x: number, y: number, w: number, h: number, color: Ink)
```

Paints a rectangle `w` by `h` pixels from x, y.

## Parameters

| Name    | Type               | Required |
| ------- | ------------------ | -------- |
| `x`     | `number`           | yes      |
| `y`     | `number`           | yes      |
| `w`     | `number`           | yes      |
| `h`     | `number`           | yes      |
| `color` | [`Ink`](/ref/Ink/) | yes      |
