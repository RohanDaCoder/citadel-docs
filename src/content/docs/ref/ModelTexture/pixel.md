title: 'modelTexture:pixel'

Part of [`ModelTexture`](/ref/ModelTexture/).

```luau
modelTexture:pixel(x: number, y: number, color: Ink)
```

Paints the pixel at x, y; `colors.transparent` makes it see-through.

## Parameters

| Name | Type | Required |
| --- | --- | --- |
| `x` | `number` | yes |
| `y` | `number` | yes |
| `color` | [`Ink`](/ref/Ink/) | yes |
