---
title: 'display.billboard'
description: 'Whether it is still present'
---

Part of [`display`](/ref/Display/).

```luau
display.billboard: Billboard
```

Whether it is still present. Read-only. Where it sits; live, every kind. Its yaw, pitch and roll in degrees; live. Pitch 90 lays a text flat on a table. Reads a vec3; write a number for every axis at once. How it turns toward the viewer; text defaults to "center", the other kinds to "fixed".
