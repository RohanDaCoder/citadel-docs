---
title: "display:move"
description: "Removes the display"
---

Part of [`Display`](/ref/Display/).

```luau
display:move(at: Vec3, rotation: Orientation ?)
```

Removes the display. Sets position and optional rotation together.

## Parameters

| Name       | Type                               | Required |
| ---------- | ---------------------------------- | -------- |
| `at`       | [`Vec3`](/ref/Vec3/)               | yes      |
| `rotation` | [`Orientation`](/ref/Orientation/) | no       |
