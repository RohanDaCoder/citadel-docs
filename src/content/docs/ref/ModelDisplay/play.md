Part of [`ModelDisplay`](/ref/ModelDisplay/).

```luau
modelDisplay:play(animation: string, opts: { speed: number ? }?)
```

Starts an animation; replaying the current one changes speed without restarting.

## Parameters

| Name        | Type                  | Required |
| ----------- | --------------------- | -------- |
| `animation` | `string`              | yes      |
| `opts`      | `{ speed: number ? }` | no       |
