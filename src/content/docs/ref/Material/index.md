A block's material as five yes-or-no questions, from `block.material`: solid, covers, firm, liquid and burns.

## Fields

| Field                                               | Purpose                                     |
| --------------------------------------------------- | ------------------------------------------- |
| [`material.solid: boolean`](/ref/Material/solid/)   | Whether the jar's Material counts as solid. |
| [`material.covers: boolean`](/ref/Material/covers/) | Grass under it dies.                        |
| [`material.firm: boolean`](/ref/Material/firm/)     | Snow and ice need it beneath them.          |
| [`material.liquid: boolean`](/ref/Material/liquid/) | Whether the jar's Material is a liquid.     |
| [`material.burns: boolean`](/ref/Material/burns/)   | Whether the jar's Material burns.           |
