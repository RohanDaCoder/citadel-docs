Part of [`Texture`](/ref/Texture/).

```luau
texture:frame(x: number, y: number, w: number, h: number, color: Ink)
```

| Name | Type | Required |
| --- | --- | --- |
| `x` | `number` | yes |
| `y` | `number` | yes |
| `w` | `number` | yes |
| `h` | `number` | yes |
| `color` | [`Ink`](/ref/Ink/) | yes |
