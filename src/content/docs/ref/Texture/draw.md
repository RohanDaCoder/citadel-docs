title: "texture:draw"

Part of [`Texture`](/ref/Texture/).

```luau
texture:draw(other: Texture, x: number ?, y: number ?)
```

Draws another texture over this one; its see-through pixels are skipped.

## Parameters

| Name    | Type                       | Required |
| ------- | -------------------------- | -------- |
| `other` | [`Texture`](/ref/Texture/) | yes      |
| `x`     | `number`                   | no       |
| `y`     | `number`                   | no       |
