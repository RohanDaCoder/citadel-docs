Helpers for persistent data views — `data.copy`, `data.insert`, `data.remove`.

Part of the [Terrain generation](/world/terrain-generation/) article.

## Functions

| Call | Purpose |
| --- | --- |
| [`copy`](/ref/data/copy/) | A detached JSON snapshot as ordinary Lua values/tables. |
| [`insert`](/ref/data/insert/) | Insert into a nested data list; omitted index appends. |
| [`remove`](/ref/data/remove/) | Remove and return a detached value; omitted index removes the last element. |
